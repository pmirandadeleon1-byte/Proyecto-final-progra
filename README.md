# Sistema de Seguimiento de Estudiantes con Riesgo de Abandono Escolar

## Descripción del proyecto

Este proyecto consiste en el desarrollo de un sistema de escritorio que permite llevar un control de los estudiantes que presentan riesgo de abandono escolar.

El programa fue desarrollado en Java, utilizando Apache NetBeans como entorno de desarrollo. Su propósito es facilitar la organización de la información de los estudiantes, docentes, cursos y responsables familiares.

Además, cuenta con opciones para configurar alertas y consultar reportes que ayuden a identificar posibles situaciones de riesgo.

El sistema fue realizado como proyecto final del curso de Programación II de la Universidad Mariano Gálvez de Guatemala.

## Objetivo del proyecto

Desarrollar un sistema que permita registrar, administrar y consultar información académica, facilitando el seguimiento de los estudiantes y contribuyendo a la prevención del abandono escolar.

## Funciones del sistema

El programa cuenta con los siguientes módulos:

### Centro educativo

Permite registrar y administrar la información del establecimiento educativo.

### Usuarios

Permite gestionar los usuarios que tienen acceso al sistema.

### Grupos

Se utiliza para organizar los diferentes grupos de estudiantes.

Permite registrar, modificar, eliminar y consultar los cursos disponibles.

## Requisitos para ejecutar el programa

Para utilizar el proyecto es necesario tener instalados los siguientes programas:

* Java JDK compatible con el proyecto.
* Apache NetBeans.
* Gestor de base de datos correspondiente.
* Controlador de conexión a la base de datos, si se requiere.

## Instalación del proyecto

### 1. Descargar el proyecto

Ingresar al repositorio de GitHub, seleccionar la opción "Code" y posteriormente "Download ZIP".

Una vez descargado, extraer los archivos en una carpeta de la computadora.

### 2. Abrir en NetBeans

1. Abrir Apache NetBeans.
2. Seleccionar File > Open Project.
3. Buscar la carpeta donde se extrajo el proyecto.
4. Seleccionar el proyecto y abrirlo.

### 3. Configurar la base de datos

1. Abrir el gestor de base de datos.
2. Localizar el archivo SQL incluido en el repositorio.
3. Ejecutar el script para crear la base de datos y sus tablas.
4. Verificar que las tablas se hayan creado correctamente.
5. Revisar la configuración de conexión del programa y colocar los datos correspondientes al servidor local.

### 4. Ejecutar el programa

1. Verificar que la base de datos esté funcionando.
2. Abrir el proyecto en NetBeans.
3. Comprobar que no existan errores de compilación.
4. Ejecutar el proyecto.
5. Iniciar sesión con un usuario autorizado.
6. Utilizar las diferentes opciones del menú principal.
